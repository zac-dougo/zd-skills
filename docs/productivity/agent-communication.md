## What it does

Makes agent chat easier to read when you return after switching tasks. It combines research-informed presentation, relaxed Simplified Technical English principles, and concise guidance for removing formulaic AI writing.

Message patterns are optional. The agent can choose its own structure while preserving clear context, evidence, qualifications, and required actions.

## When to reach for it

Type `/agent-communication`, or the agent can reach for it automatically when a task fits. Use it for progress updates, results, decisions, and explanations in chat.

- For technical documentation, use [technical-writing](https://aihero.dev/skills-technical-writing).
- For instructions that other agents will follow, use [writing-for-agents](https://aihero.dev/skills-writing-for-agents).

## Common questions

**Does every response need a prescribed message type?**
No. Patterns are starting points. A short answer can be one sentence; a complex answer can use another structure when it helps the reader.

**Does it require a separate writing-style skill?**
No. It includes readability principles and condensed guidance for removing AI writing patterns. It does not ask the agent to add personality or emotional reactions.

**How are labels and supporting details formatted?**
A bold lead-in can sit on its own line, with supporting bullets or indented text immediately beneath it. There is no empty line between the label and its detail. Italics provide lighter emphasis within prose.

## It's working if

- You can return to a chat and identify the task, current result, and any required reply without reconstructing the conversation.
- Qualifications appear beside the claims they limit, and verified results are distinguishable from assumptions.
- Labels and supporting details are easy to distinguish without adding a heading to every answer.
- Responses preserve useful reasoning while dropping filler and repeated summaries.

## Where it fits

This is a standalone skill for everyday agent chat. [Technical-writing](https://aihero.dev/skills-technical-writing) covers documentation, while [writing-for-agents](https://aihero.dev/skills-writing-for-agents) covers instructions intended for agents to follow.
