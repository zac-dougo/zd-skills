## What it does

Sharpens a plan through focused questioning without writing repository state. It uses the grilling workflow, with exhaustive depth available when requested.

## When to reach for it

Invoke `$grill-me` in Codex or `/grill-me` in Claude Code when you want to think through an idea before committing to work.

## Common questions

**Does it write a spec or change the project?**

No. The result is the discussion and its decisions. Use a documentation or implementation workflow when you want those outputs.

## It's working if

- You get concrete recommendations and consequential questions.
- No repository files change as a side effect of the discussion.

## Where it fits

This is the discussion-only counterpart to grill-with-docs. See the [collection guide](https://github.com/zac-dougo/zd-skills/blob/main/README.md) for related workflows.
