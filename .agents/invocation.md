# Invocation and composition

The maintained rules for skill metadata, explicit invocation, and portable dependencies live in [skill mechanics](../skills/productivity/writing-for-agents/SKILL-MECHANICS.md). Read that reference when creating, moving, or changing a skill's invocation policy.

Every promoted skill has matching Claude Code frontmatter and Codex `agents/openai.yaml` metadata. Bucket READMEs and the top-level README distinguish user-invoked and model-invoked skills.

Read-only shared guidance is a plain reference, not another discoverable skill. Merely reading project vocabulary does not invoke `domain-modeling`; that skill applies when actively developing the domain model.
