# Research

Establish the question, the evidence needed, and what would answer it. Follow the user's scope and requested output. A focused lookup can end with a cited answer; a larger investigation may need a durable document.

## Divide useful independent work

Delegate bounded searches or source checks when parallel reading or a separate context is likely to improve the result or reduce completion time. Follow the shared model-selection policy, preferring an available Luna model for focused fact gathering and escalating when the question needs stronger reasoning.

If you are already a delegated researcher, complete the assigned investigation directly. Delegate further only when the coordinator explicitly requests it. Give the coordinator findings and evidence rather than repeating the delegation instructions.

## Establish the facts

- Prefer the sources that own the answer: official documentation, source code, specifications, research papers, and first-party APIs. Use secondary sources as leads and follow material claims back to primary evidence.
- Check versions, dates, and applicability where they affect the answer. Separate observed facts, interpretation, and remaining uncertainty.
- Cite the source beside each material claim. Check that the cited passage supports the claim; a plausible title or search snippet is insufficient.
- Stop when the question is answered with adequate evidence. Explain unavailable evidence rather than extending the investigation into unrelated topics.

## Return the findings

Return the answer, supporting citations, and relevant limitations. Save a document when the user requests one or an established project workflow requires a durable artifact. Use the requested destination or the project's existing convention; do not create a repository note for every lookup.

When saving a document, include its scope, source versions or dates when relevant, and unresolved questions. Report its location. Research alone does not authorize implementation, publication, or changes to project policy.
