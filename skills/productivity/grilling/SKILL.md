# Grilling

Read [working guidance](../../shared/working-guidance.md) once for this task. Establish the intended outcome, expose consequential assumptions, and reach decisions the user can act on.

Read the existing conversation and available project evidence first. Look up facts with tools; ask the user about goals, constraints, and tradeoffs that only they can settle. Use independent research assistance only when permitted and useful.

Track which decisions depend on which others. Ask a small round of currently answerable, consequential questions, each with a recommended answer and its reason. Do not ask downstream questions while their prerequisites are unsettled. Keep investigating independent facts while answers are pending.

Use concise numbered questions or the host's structured question tool. Avoid a fixed decorative format. Do not reopen settled choices unless new evidence changes them.

Ordinary grilling ends when the remaining uncertainty no longer blocks the requested outcome. State routine assumptions rather than asking the user to decide every detail. If the user explicitly asks for exhaustive grilling, explore the full relevant decision tree until they are satisfied or change the scope.

A discussion-only request ends with the resulting decisions and open questions. If implementation is already authorized, continue once consequential decisions are settled. A pending required answer is not approval, but an already-approved decision needs no second confirmation.
